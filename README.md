# Data Analysis Projects

A collection of data analysis projects using Excel, SQL, Power BI, Python, and other tools to explore datasets, uncover insights, and support data-driven decision-making.

## About This Repository

This repository contains practical data analysis projects focused on transforming raw data into meaningful insights through data cleaning, analysis, visualization, and reporting.

The projects are designed to demonstrate practical analytical skills and the use of different tools for solving business and operational problems.


## Projects

### 1. Manufacturing Production Analysis Using SQL

An SQL-based analysis of manufacturing production data using MySQL.

The project focuses on:

- Production target vs. actual production
- Production achievement
- Department performance
- Shift performance
- Product performance
- Defects and quality status
- Downtime analysis
- Business-oriented SQL queries and insights

**Tools:** MySQL, SQL

[View SQL Project](./Manufacturing-Production-SQL-Analysis/)


### 2. Manufacturing Production Analysis & Dashboard Using Excel

An Excel-based manufacturing analytics project featuring data cleaning, formula-based analysis, Pivot Tables, dynamic filtering, and an interactive dashboard.

The project focuses on:

- Production target vs. actual production
- Production achievement
- Department and shift analysis
- Product performance
- Quality analysis
- Downtime analysis
- Interactive KPI dashboard
- Slicers and charts
- Management-oriented insights

**Tools:** Microsoft Excel

[View Excel Project](./Manufacturing-Production-Excel-Analysis/)
